# JMA AI 寶石鑑賞挑戰

目標頁面 `https://xiu.teslaone.com.cn/youxi/index.html` 的本地可運行復現，並按
`AI遊戲 Q&A revised.docx`、`AI小遊戲_流程.docx` 更新題庫與流程。

## 使用方式

直接雙擊 `index.html`，不需要安裝依賴。

## 已復現功能

- 授權勾選後解鎖開始按鈕，並以本機紀錄限制每位玩家玩一次
- 從 1–29 正誤題或 30–50 四選一題中隨機選一組，再抽 5 題
- 每題顯示對應寶石圖案、知識主題與 AI 導師即時分析
- 50% 分界，3 題或以上為結論 A，低於 3 題為結論 B
- 報告顯示正確率、答對題數、錯題複習方向與禮物結論
- 提醒到登記處領取禮物，並參加 IJDC 最受公眾歡迎作品獎投票
- 完成與關閉彈窗
- QR Code 放大查看
- 桌面與手機響應式版面
- 鍵盤 Esc 關閉、焦點管理與 reduced-motion 支援

## 邊界

- 本版本不串接原站後端、帳號、抽獎或投票資料。
- 禮物結果只在前端顯示，不會提交或兌換。
- 「每人限玩一次」目前使用瀏覽器 localStorage 做前端限制，清除網站資料、換瀏覽器或換裝置後仍可重玩；正式上线若需可靠限制，必須由後端綁定玩家身份。
- 入口 QR Code 目前沿用目標站素材作視覺佔位；正式遊戲 QR 需待部署網址確定後生成並替換。
- 可用 `index.html?set=A` 或 `index.html?set=B` 指定題組作驗收；正常入口會隨機選組。
